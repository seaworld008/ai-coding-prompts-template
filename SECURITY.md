# Security Policy

## 中文说明

这个仓库主要收录的是 AI 编程提示词、模板文档和相关整理内容，不是一个提供线上服务的应用项目。

如果你发现的是以下问题，欢迎反馈：

- 仓库内容中存在明显的安全误导
- 某些提示词会诱导生成高风险、不安全的默认做法
- 文档中的命令、配置或操作建议存在明显安全隐患
- 仓库依赖的外部链接存在可疑风险

## How To Report

If you believe you found a security-related issue in this repository, please report it responsibly.

Recommended approach:

1. Open a private channel first if the issue could cause harm when disclosed publicly.
2. Include the affected file path, the risky content, and why it may be unsafe.
3. If possible, suggest a safer alternative or the expected secure default.

If the issue is low risk and primarily documentation-related, opening a GitHub issue is also acceptable.

## Scope

This repository is primarily a documentation and prompt-template repository.

That means:

- most security concerns here are about unsafe guidance, risky defaults, or misleading examples
- there may not always be a traditional software vulnerability to patch
- fixes will usually be documentation corrections, safer prompt wording, or clearer caveats

## Responsible Disclosure

Please avoid publishing exploit-style instructions or harmful abuse workflows directly in public issues if the wording could be copied and misused.

When in doubt, report conservatively first.
