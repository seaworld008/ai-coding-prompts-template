# Open Source Repository Polish Design

## 背景

当前仓库已经具备：

- 基础开源目录结构
- 清晰的 README 导航
- 通用版和专用版文档
- GitHub 描述和 topics

但从一个“成熟开源项目首页”的角度看，仍有三块可以继续补强：

- 缺少安全披露入口
- 缺少行为规范文档
- README 首屏还可以更像一个公开项目首页，而不只是文档索引

## 目标

把仓库进一步整理成更完整的开源项目样板，同时不破坏当前的中文主叙事风格和 Markdown 简洁结构。

## 方案对比

### 方案一：只补标准文件

补 `SECURITY.md` 和 `CODE_OF_CONDUCT.md`。

优点：

- 成本最低
- 风险最小

缺点：

- README 首屏提升有限

### 方案二：开源仓库增强包

补 `SECURITY.md`、`CODE_OF_CONDUCT.md`，并升级 README 首屏结构。

优点：

- 提升最均衡
- 更像成熟开源仓库
- 不需要引入模板噪音

缺点：

- 需要小幅重排 README 前半部分

### 方案三：完整社区模板化

额外加入 issue templates、PR template、support 文档等。

优点：

- 形式最完整

缺点：

- 当前阶段略重
- 会让仓库从“内容模板仓库”变成“流程模板仓库”

## 推荐方案

采用方案二。

## README 调整原则

- 保留现有标题和主路径
- 增加一段更像公开项目首页的中英文简介
- 增加“适合谁使用”“仓库结构”这类首屏信息
- 保持快速跳转区仍然明显

## 新增文件原则

### SECURITY.md

- 写清楚如何报告问题
- 说明当前仓库主要是文档和提示词内容仓库
- 不夸大安全能力

### CODE_OF_CONDUCT.md

- 使用简洁、通用、正向的社区行为规范
- 不写过于复杂的治理术语

## 非目标

- 暂不增加 `.github/ISSUE_TEMPLATE`
- 暂不增加 PR 模板
- 暂不引入徽章墙
